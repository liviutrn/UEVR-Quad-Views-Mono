# The code that actually runs (CI78), readable

Generated by `python tools/assemble_source.py OUT --review`, which replays the
whole patch stack (stage1 ... ci78) exactly as the Windows workflow does, on
Joey's public UEVR (5ac7edc) and frontend (60be4b0). Do not edit these files;
they are a mirror for reading and review. Regenerate after every new ciNN layer.

- `new/` — files DuoView added (shaders, compositor, depth capture, recorder),
  complete. Start with `new/src/mods/vr/DuoViewStereoCompositeRaster.hlsl`
  (final per-eye image), `DuoViewSurfaceReproject.hlsl` and
  `DuoViewDetailTransfer.hlsl` (RIGHT fovea), `DuoViewD3D12.hpp` (what runs
  each frame) and `DuoViewSurfaceD3D12.hpp` (surface passes).
- `changed/` — what DuoView changed inside Joey's UEVR files, as diffs
  (`VR.cpp`, `D3D12Component.cpp`, hooks ...). Much smaller than the full files.
- `DuoViewShaderSource.hpp` (compiled shader bytes) is left out: only the
  Windows build produces real bytecode.

Every layer up to CI77 verifies its own before/after fingerprints while being
replayed, so these files match the CI build byte for byte (the recorder's build
commit string reads `UNVERSIONED_LOCAL_BUILD` locally).
