# Baseline Joey STALKER 2 DIBR review

Scope: stock Joey stereo DIBR / DIBR Single View only. No DuoView overlay.

Independent review performed with Astra medium and GPT-5.6 Sol high; Luna 6
max checked provenance, build inventory, constant packing, and test oracles.

## Corrected findings

- Queue submission: R2 recorded 35,772 captures without submitting any. R3
  hooks the live presentation and native Streamline queues, preserves each
  forwarding slot original, and fences alternate direct producers.
- Viewport provenance: publication uses the latest ordered producer binding,
  rather than a larger rectangle from an unsubmitted command list. A -> B -> A
  retains the final rectangle. Windows GPU regression covers both.
- Reprojection strength: scale the forward map, not the iterative solver gain.
  The former strength=2 cancellation is tested against exact plane pixels at
  0, 0.5, 1, 1.5, and 2. Repair residual uses the same strength.
- Single-view activation: require main viewport Draw, stereo enabled, exact
  validated viewport/scene, matching output generation, three stable main
  families, and three consecutive ready outputs. Failed output resets warmup.
- Current Windows verification runs the complete original compatibility suite.

## Reviewed limits

The existing scalar X baseline was retained. A replacement for nonparallel,
fully canted eye poses needs measured pose fixtures and parity validation; no
actual PSVR2 pose evidence here establishes an error requiring that change.
No speculative coordinate transform was introduced.

The largest valid current-Present main viewport preference was retained.
Recording serial alone cannot establish execution order across parallel lists.

GPU fixture uses production capture and shader code plus real queue detours;
barrier/viewport events are supplied by the standalone fixture. STALKER 2 and
a headset are unavailable in CI. No in-game success is asserted by this review.
