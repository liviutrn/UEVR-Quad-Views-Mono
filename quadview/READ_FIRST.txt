UEVR QUAD VIEWS STEREO — BUILD 41 (EXPERIMENTAL)

Target: STALKER 2 UE5.5 / DX12 / OpenXR.
ID7: Quad Views Stereo (Experimental), four engine views and two distinct eyes.
ID6: preserved monoscopic DuoView baseline.

These instructions apply to the compiled Windows package after successful CI.
The repository source snapshot alone is not installable.

Use the complete compiled package, extracted to a new folder. Run its included
injector using your known-working game and SteamVR/OpenXR setup. Keep your
working Build 182/39/40 folders available for comparison.

Turn off Extreme Compatibility, split-screen, SceneView compatibility,
2D Screen, and Stereo Emulation. Select Quad Views Stereo (Experimental), ID7.

First test: gaze OFF, sharpening 0, focus width/height 50%/50%, context 20%.
Use a known-safe resolution. Check stereo depth, focus alignment, head movement,
and sustained frame delivery. Then enable gaze and compare sharpening 0/1/2.
Existing saved settings are respected; these first-test choices are manual.

Build 41 fixes stale atlas/pose selection and an exact-owner drain stall.
Unknown ownership or terminal tail-hook failure now blocks stale submission
and reports: "ID7 ownership proof lost; restart game required".
Restart the game if this appears; do not force-clear a blocked transition.

Test 7 -> 6 -> 0 -> 7 transitions and 30–60 minutes of ordinary gameplay.
Keep NVIDIA Smooth Motion disabled when comparing frame delivery.

If a problem occurs, preserve the complete UEVR log and any game crash log/dump.
Useful stages: GTProducer, RenderFamily, RHI, CopyEnqueued, Submit.
Diagnostic modes: 0 blend, 1 context, 2 focus, 3 synthetic layout colors.

See QUADVIEW_RELEASE_NOTES.md in the package (quadview/RELEASE_NOTES.md in
the source tree) and BUILD41_REVIEW.md for changes and limits.
The original RenderThread crash is NOT proven fixed. CI cannot establish
headset stability, shading parity, or performance gains.
