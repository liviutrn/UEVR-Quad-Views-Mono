Empty mask: count0, null metrics and EMPTY_NOT_PASS; target weapon/layers halo requires >=16 pooled pixels per eye or INVALID. No zero-valued empty pass.

Read back actual conditioned inverse depth at that source UV; report absolute inverse-meter error in the same regions. It is not conceptual donor depth or proof of hidden-background recovery.

Report per-transition deltas then worst transition, never difference of independently selected maxima. This baseline task has only explicitly labelled self-reference zero deltas; no candidate claim.
