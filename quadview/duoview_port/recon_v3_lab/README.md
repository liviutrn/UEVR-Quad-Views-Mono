# V3 independent corpus WARP replay — measurement harness

This harness is **test-only**. It does not change the production HLSL, Stereo Cleanup V2, or the playable backend. It runs 20 original V3 synthetic RGB-D frames through the actual generated Direct3D 12 WARP compositor, plus five zero-stereo source-alignment captures. The reference left/right RGB and object IDs are evaluator-only and never uploaded as D3D12 resources.

## CI input generation

```bash
python -m pip install numpy==2.3.5 scipy==1.17.0 opencv-python-headless==4.13.0.92 Pillow==12.3.0
python quadview/duoview_port/recon_v3_lab/export_recon_inputs.py --out quadview/duoview_port/recon_corpus_generated --frames 4 --scenarios weapon layers stationary_false49 physical_sway
python quadview/duoview_port/recon_v3_lab/verify_recon_v3.py --corpus quadview/duoview_port/recon_corpus_generated --expected quadview/duoview_port/recon_v3_lab/expected.json --check-projection
```

The verifier rejects any corrupted or stale input/GT file, wrong scene, frame, type, size, content hash or source-to-eye matrix. Independent V3 GT and IDs are stored in the generated test corpus for *offline scoring only*, not used by the GPU harness.

## GPU WARP

The extra overlay `ReconV3CorpusWarpOverlay.py` is applied after the existing calibrated `ReconLargeWarpOverlay.py` on its generated C++ fixture. It imports native-color source rectangles of 96×54 periphery and 192×108 fovea, plus 384×216 coarse/fine inverse depth (R32 typeless storage, R32 float SRV). Camera homographies are identity except for pan-mode weapon/layer stereo frames, matching the original V3 `Hcoords()`. One output stereo frame per input; one extra zero-stereo calibration per scene.

Run after normal CMake configure/build on Windows:

```powershell
ctest --test-dir duo_b40_tests -C Release --output-on-failure -R '^duoview-reconstruction-v3-corpus-warp$'
```

The output `recon_v3_<scene>_fN.bgra` contains packed BGRA8 left then right at 768×216; `recon_v3_zero_<scene>_f0.bgra` provides calibrated source registration. `recon_v3_capture_contract.jsonl` has 25 records with exact frame identity, active rectangles, signed eye factors and H coefficients. CI copies all into the official evidence artifact.

## Score outputs (run **only after** WARP completes)

```bash
python quadview/duoview_port/recon_v3_lab/score_warp_v3.py \
 --corpus quadview/duoview_port/recon_corpus_generated \
 --captures /path/to/unzipped/official/evidence \
 --out ./v3_score
```

The evaluator first requires zero-stereo source registration for *every* scene; until it passes, no baseline stereo ranking is emitted. Scorecard has per-scene/frame/eye RGB8 MAE, p95/p99 on true ID-based object boundaries, foreground and background edges, mono-visible versus occluded GT, and top-5 visual differences. **No GPU timestamps, true DLSS inputs, per-pixel source owner or real headset measurements are claimed.**
